# Example fixture attribution

Every binary or data asset under this directory is recorded in
`manifest.json` with an exact SHA-256 digest, origin and licence.

## CyberTexel-generated fixtures

The following assets are original deterministic test data produced for this
repository and distributed under the project's Apache-2.0 licence:

- `meshes/quad_uv.obj`
- `meshes/quad_udim.obj`
- `maps/ambient_occlusion.png`
- `maps/curvature.png`
- `maps/normal_opengl.png`
- `maps/position.png`
- `maps/manifest.json`
- `alphas/soft_round.png`
- `images/checker.png`

The PNG files are regenerated by `generate_images.py` using only Python's
standard library. They contain no metadata, random values or external source
pixels.
