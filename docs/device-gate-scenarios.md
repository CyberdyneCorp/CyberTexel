# Device-gate scenario coverage

The `device-gate-policy` test validates the versioned budget manifest and every
decision rule without treating fixture numbers as hardware measurements. Real
runs use `just gate-budgets` with a dated result from an exact reference device;
absent hardware remains explicitly unmeasured.

| OpenSpec scenario | Executable evidence | What is asserted |
| --- | --- | --- |
| Figure from an unnamed machine | `device-gate-policy` | A non-reference device is informational and cannot satisfy coverage. |
| Every budget is named | `device-gate-policy` | All nine operations have numeric device- and configuration-scoped budgets. |
| A stamp is within budget | `device-gate-policy` | Stamp median and p95 are independent decisions against numeric ceilings. |
| Same stamp, larger canvas | `device-gate-policy` | The 2048/16384 ratio passes at the touched-area factor and fails at linear growth. |
| Unreachable budget | `device-gate-policy` | A value below the absolute floor is unreachable, never passed. |
| Stamps measured in a batch | `device-gate-policy` | Per-stamp batches fail unless fixed batch cost was excluded. |
| Reporting coverage | `device-gate-policy` | Only passed and failed decisions count; timed but unmeasured rows remain uncovered. |
| Tablet reference device unavailable | `device-gate-policy` | Missing tablet measurements remain unmeasured and are never replaced by desktop data. |
| Memory budget on the tablet | `device-gate-policy` | Stroke, composite, smart-material and export byte ceilings are required for the tablet. |
| Reproducing a claim | `device-gate-policy` | Device, date, commit and command metadata are mandatory. |
| A change makes strokes slower | `device-gate-policy` | A result beyond the baseline variance fails and names the baseline. |
| Reading current performance | `device-gate-policy` | The checked Markdown document is generated byte-for-byte from the manifest. |
| Fast submission but delayed presentation | `device-gate-policy` | Input, queue, upload, execution and presentation stages must sum to measured latency. |
| Thermal slowdown | `device-gate-policy` | Twenty minutes, the final five-minute window, thermal/memory data and recovery fixtures are mandatory. |
| Hidden round trip | `device-gate-policy` | Any synchronous readback bytes during resident paint or undo exceed the zero-byte ceiling. |
