# CyberTexel v0.1.0

Initial public release of the headless C++20 texture engine and its host-facing APIs.

## Included

- Sparse tiled channels, layers and masks, undoable texture-set transactions, and bulk channel writes.
- Mesh and UV ingest, picking, painting, material graphs, shader emission, texture export, and project save/load.
- A stable C ABI, Python, Swift and Rust bindings, and a headless CLI.
- Reference desktop WGSL and iPad Metal hosts with measured input-to-visible and residency paths.

## Packages

- `cybertexel-0.1.0-linux-x64.zip` — Linux x86-64 library, headers and CLI; consumer smoke test executed.
- `cybertexel-0.1.0-macos-universal.zip` — macOS arm64/x86-64 library, headers and CLI; consumer smoke test executed.
- `cybertexel-0.1.0-ios-arm64.zip` — iOS arm64 library and headers; consumer smoke test linked. This is a library package, not an iPad app.

Each archive includes its package manifest, licence and third-party notices.

## Current limits

Windows and Android packages are deferred. The performance budget table has 16 measured cases out of 30; 15 pass. The position-gradient generator exceeds its 100 ms budget and remains open for optimization. The other unmeasured budgets are not claimed as passes.
