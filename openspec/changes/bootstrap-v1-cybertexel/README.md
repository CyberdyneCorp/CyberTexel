# bootstrap-v1-cybertexel

Greenfield v1: a portable C++20 3D texture-painting and PBR material-authoring
engine — layer stack, texture-space paint rasterization, node-graph materials
compiled to shader source, smart materials and channel-packing export — with
Python, Swift and Rust bindings, consuming UVs and baked maps from
CyberRemesherAndUV and owning no GPU device in the host-executed path.
